3. Regras de negócio — precificação (obrigatório detalhar)

Documentar a fórmula usada no sistema:

  • Base: percentual mensal sobre valor FIPE por faixa (até R$ 30k, 30–60k, 60–100k, acima 100k)
  • Ajustes: idade do veículo, tipo de uso (particular/comercial/app), garagem fechada, UF de risco
  • Cobertura padrão: 100% FIPE; franquia: 5% do valor coberto
  • Incluir exemplo numérico: carro R$ 50.000 → mensalidade aproximada

4. Arquitetura — o que incluir no documento

  • Diagrama de camadas: Frontend (HTML/CSS/JS) → API REST (Express) → SQLite
  • Pastas do projeto: frontend/, backend/, database/migrations/
  • Fluxo de autenticação: login → JWT no localStorage → header Authorization
  • Diagrama de sequência simples: “Contratar proteção” (cotação → apólice → parcelas)

2. Relacionamentos e cardinalidades

RelacionamentoCardinalidadeRegra

USUARIO contrata APOLICE1 : NHistórico de apólices
